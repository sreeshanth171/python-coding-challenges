# Week 02 - Sum of Even Numbers

## Problem

Write a Python program that takes a positive integer `n` as input and calculates the sum of all even numbers from 1 to `n`.

The program should also count how many even numbers were found.

## Requirements

- Use a loop.
- Use an if statement to check whether a number is even.
- Do not use Python's built-in `sum()` function.
- The program should work for any positive integer.

## Sample Input

10

## Sample Output

Sum of even numbers: 30
Number of even numbers: 5

## Explanation

The even numbers from 1 to 10 are:

2 + 4 + 6 + 8 + 10 = 30

There are 5 even numbers.

## Language

Python
