
# Airbnb Homepage Clone

A responsive Airbnb-inspired homepage built using HTML and CSS as part of my Week 05 coding challenge.

## About the Project

This project recreates the design of a travel accommodation website with a modern layout, attractive property images, popular destinations, and featured stays.

The objective is to improve my frontend development skills by building a complete webpage using HTML and CSS.

## Features

- Navigation bar with logo, links, login, and signup buttons
- Search section with location, check-in, check-out, and guest selection
- Hero section with a travel image and call-to-action button
- Six popular destination cards
- Eight featured property cards with ratings and prices
- Travel experiences promotional section
- Footer with support, hosting, privacy, terms, and social media links
- Responsive layout for desktop, tablet, and mobile screens

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Google Fonts
- Font Awesome
- Unsplash Images

## How to Run

1. Clone or download the repository.
2. Open the `week-05` folder.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension in Visual Studio Code.

An internet connection is required to load external fonts, icons, and images.

## Learning Outcomes

- Practiced semantic HTML structure.
- Improved CSS styling and layout skills.
- Learned to use Flexbox and CSS Grid.
- Practiced responsive web design with media queries.
- Improved webpage organization and visual presentation.

## Limitations

This is a frontend-only educational project. Search, login, signup, and favourite buttons do not have backend functionality. Property details, ratings, and prices are illustrative.
