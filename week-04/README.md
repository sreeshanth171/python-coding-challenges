# Week 04 – Student Database (SQLite)

A menu-driven Student Management System built with Python and SQLite.

## Features

- Add a student
- View all students
- View passing students (Grade ≥ 70)
- Show average grade
- Search a student by name
- Delete a student by ID

## Technologies Used

- Python 3
- SQLite3

## How to Run

```bash
python main.py
```

## Sample Menu

```
===== Student Management System =====
1. Add student
2. View all students
3. View passing students
4. Show average grade
5. Search student
6. Delete student
7. Exit
```
