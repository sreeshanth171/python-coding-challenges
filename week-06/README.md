
# Zomato Homepage Clone

A responsive food discovery and restaurant listing homepage built using HTML and CSS as part of my Week 06 coding challenge.

## About the Project

This project recreates a modern food discovery website inspired by Zomato. It includes a navigation bar, search section, food categories, popular restaurant listings, promotional offers, and a footer.

## Features

- Navigation bar with Zomato logo, restaurant search link, add restaurant link, login, and signup
- Search section with location and restaurant or dish inputs
- Hero section with food background image and call-to-action button
- Six food category cards
- Eight restaurant cards with cuisine, ratings, cost for two, and delivery time
- Three special offer cards with Order Now buttons
- Footer with company information, restaurant partnerships, customer support, privacy policy, terms, and social media icons
- Responsive desktop, tablet, and mobile layouts

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Google Fonts
- Font Awesome
- Unsplash Images

## How to Run

1. Clone or download the repository.
2. Open the `week-06` folder.
3. Open `index.html` in your browser.
4. Alternatively, use Live Server in Visual Studio Code.

An internet connection is required to load the external fonts, icons, and images.

## Learning Outcomes

- Practiced semantic HTML.
- Improved CSS styling and layout skills.
- Used Flexbox and CSS Grid to create card layouts.
- Practiced responsive design with media queries.
- Built a complete multi-section frontend webpage.

## Limitations

This is a frontend-only educational project. Search, login, signup, and order buttons do not connect to a backend. Restaurant details, ratings, prices, delivery times, and offers are illustrative.
