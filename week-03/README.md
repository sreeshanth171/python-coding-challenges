# Week 03 - Stone Paper Scissor Game

## Problem

Write a Python program to play a Stone-Paper-Scissors game against the computer.

## Requirements

- The user enters one of: `stone`, `paper`, or `scissor`
- The computer randomly chooses one option
- Decide the winner using the game rules
- If both choices are the same, it's a draw
- Print both choices and the result

## Sample Input

stone

## Sample Output

Your choice: stone

Computer choice: scissor

Result: You Win!

## Language

Python
